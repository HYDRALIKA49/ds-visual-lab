What is a data structure?

A data structure is a way of organizing data so a program can store, access, update and process it efficiently.

Think of it as a container

An array is like numbered lockers. A stack is like a pile of plates. A queue is like people waiting in line. A tree organizes information hierarchically.

Why do we need them?

The same data can be arranged in different ways. That choice changes how quickly operations such as search, insertion and deletion can be performed.

Sorting

Bubble: simple, usually O(n²).

Selection: O(n²), few swaps.

Insertion: O(n²) worst case, excellent for nearly sorted data.

Quick: O(n log n) average, O(n²) worst case.

Searching

Linear: works on unsorted data, O(n).

Binary: requires sorted data, O(log n).
