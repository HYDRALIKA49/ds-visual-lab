# 📊 Data Structures & Algorithms Visual Lab

An interactive, self-contained educational tool for learning Data Structures and Algorithms through visual animations and step-by-step execution.

## ✨ Features

### 📚 Foundational Topics
- **Data Structures**: Arrays, Linked Lists, Stacks, Queues, Trees, Heaps, Hash Tables, Graphs
- **Algorithms**: Linear Search, Binary Search, Bubble Sort, Selection Sort, Insertion Sort, Quick Sort

### 🚀 Advanced Topics
- **Advanced Trees**: AVL Trees, Red-Black Trees, B-Trees, Trie (Prefix Tree)
- **Graph Algorithms**: Dijkstra's Algorithm, A* Search, MST (Kruskal/Prim), Topological Sort, Floyd-Warshall
- **Dynamic Programming**: Knapsack (0/1), Longest Common Subsequence, Edit Distance, Matrix Chain
- **String Algorithms**: KMP, Rabin-Karp, Z-Algorithm, Suffix Array
- **Greedy Algorithms**: Activity Selection, Huffman Coding, Coin Change, Fractional Knapsack
- **Advanced DS**: Union-Find, Fenwick Tree, Segment Tree, Bloom Filter, Sparse Table
- **Network Flow**: Ford-Fulkerson, Edmonds-Karp, Dinic's, Min-Cut
- **Machine Learning**: KNN, K-Means, Decision Trees, Naive Bayes
- **Cryptography**: RSA, AES, Hash Functions, Diffie-Hellman
- **Game Theory**: Minimax, Alpha-Beta Pruning, Nim Game, MCTS

### 🎯 Interactive Features
- **Step-by-step execution** with visual feedback
- **Custom data input** for testing your own values
- **Animation speed control** (0.5x - 3x)
- **Code synchronization** showing corresponding implementation
- **Topic-specific exercises** to test understanding
- **Progress tracking** with localStorage
- **Keyboard shortcuts** for faster navigation

## 🎮 Keyboard Shortcuts
- `Space` → Play/Pause
- `→` (Arrow Right) → Next Step
- `R` → Reset
- `1-5` → Speed Control (1=0.5x, 2=1x, 3=1.5x, 4=2x, 5=3x)

## 🚀 Getting Started

1. Open `index.html` in your browser
2. Navigate topics using the sidebar
3. Click **"Play Demo"** to watch automatically
4. Use **"Next Phase"** for step-by-step learning
5. Try custom data with **"Run with Custom Data"**

## 💻 Technologies Used
- Pure HTML/CSS/JavaScript (no external dependencies)
- LocalStorage for progress tracking
- CSS animations for visual feedback

## 📚 Learning Path

### Beginner Level
1. Overview → Data Structures → Simulator
2. Linear Search → Binary Search
3. Bubble Sort → Selection Sort

### Intermediate Level
1. AVL Trees → Red-Black Trees
2. Dijkstra's Algorithm → A* Search
3. Knapsack Problem → LCS → Edit Distance
4. KMP Algorithm → Rabin-Karp

### Advanced Level
1. Network Flow (Ford-Fulkerson → Dinic's)
2. Machine Learning (KNN → K-Means)
3. Cryptography (RSA → AES)
4. Game Theory (Minimax → MCTS)
